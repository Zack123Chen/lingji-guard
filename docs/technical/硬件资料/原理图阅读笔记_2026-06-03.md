# ESP32-S3 硬件原理图阅读笔记

源文件：`SCH_Schematic1_2026-06-03.pdf`

## 核心器件

- 主控：ESP32-S3R8
- Flash：W25Q64JVSSIQ
- PSRAM：APS6404L-SQN-SN
- USB：Type-C 接口，另有 CH340X 串口下载/调试链路
- 电源：锂电池充电、3V3、2V、1V2、2V8 等电源轨

## 固件重点引脚

| 信号 | ESP32-S3 GPIO | 用途 |
| --- | ---: | --- |
| INT1 | GPIO1 | 加速度计中断 |
| CS1 | GPIO2 | SPI 片选，疑似加速度计 |
| CS2 | GPIO3 | 屏幕 SPI 片选 |
| PWRON | GPIO4 | 电源保持/开机控制 |
| EN1 | GPIO5 | 功放使能 |
| EN2 | GPIO6 | 外部模块使能 |
| EN3 | GPIO7 | 充电/电源相关使能 |
| SDA | GPIO8 | I2C 数据 |
| SCL | GPIO9 | I2C 时钟 |
| EN4 | GPIO10 | 外设使能 |
| MOSI | GPIO11 | SPI MOSI |
| SCLK | GPIO12 | SPI SCLK |
| MISO | GPIO13 | SPI MISO |
| CDIN | GPIO14 | TF 卡检测 |
| U1TX | GPIO17 | 外部串口 TX |
| U1RX | GPIO18 | 外部串口 RX |
| CLK | GPIO19 | 摄像头时钟 |
| DC | GPIO20 | 屏幕 DC |
| BL | GPIO21 | 屏幕背光 |

## 屏幕接口 P3

原理图里的屏幕接口是 SPI 屏接口：

| P3 引脚 | 信号 |
| ---: | --- |
| 1 | GND |
| 2 | 3V3 |
| 3 | SCLK |
| 4 | MOSI |
| 5 | RST1 |
| 6 | DC |
| 7 | CS2 |
| 8 | BL |

当前 ST7789 测试程序应按原理图最终改成：

```text
BL  -> GPIO21
CS  -> GPIO3
DC  -> GPIO20
SDA -> GPIO11
SCL -> GPIO12
VCC -> 3V3
GND -> GND
```

注意：原理图屏幕接口有 `RST1`，但 OCR/原理图文本没有明确给出它连接到哪个 ESP32 GPIO。拿到硬件后需要实测或查 PCB/netlist；如果屏幕背光亮但无画面，优先确认 `RST1`。

## 其他外设

- 摄像头接口 U11：包含 VSYNC、HREF、RESETB、D0-D7、PCLK、FLASH、PWDN、SCL、SDA。
- TF 卡 CARD1：使用 DATA0、CMD、CLK、CDIN，并有 3V3 供电。
- 温度传感器 U7：TMP117AIDRVR，走 I2C，含 ALERT 中断。
- 加速度计 U8：ADXL362BCCZ-RL7，走 SPI，含 INT1/INT2。
- 音频：
  - 麦克风 MIC1，2V 供电，输出 MIC+。
  - 功放 U10：PAM8302AADCR，EN1 控制，输入 IN+/IN-，输出到 SPK1。
- 扩展接口：
  - H1：IRD、RD 等传感器信号。
  - H2：GND、SCL、SDA、3V3。
  - P1/P2：5V、GND、USB、U1TX/U1RX、EN2/BOOT/NET 等。

## 到板后的最小 bring-up 顺序

1. 只接 USB，确认 3V3 正常、串口可下载、BOOT/RESET 可用。
2. 点亮屏幕背光 `GPIO21`，再初始化 ST7789。
3. 扫描 I2C `GPIO8/GPIO9`，确认 TMP117 等设备响应。
4. 初始化 SPI 总线 `MOSI=GPIO11, SCLK=GPIO12, MISO=GPIO13`，分别验证屏幕、ADXL362、TF 卡。
5. 验证功放前先保持 `EN1=LOW`，避免上电爆音；输出测试音前再打开。
6. 摄像头最后验证，先确认 PCLK/VSYNC/HREF/D0-D7 引脚表，再写采集程序。
