## 一、先搞清楚：你必须做什么、可以不做什么

| 场景 | 你需要做什么 |
|------|-------------|
| **大一年度项目结题** | 必须在"全国大学生创业服务网" cy.ncss.cn 完成报名（需要报名成功截图才能结题） |

## 五、赛道选择（你大概率走这个）

你是大一本科生，做的是大一年度项目 → **高教主赛道 · 创意组**

### 高教主赛道 创意组 评审标准（总分100）

| 维度 | 分值 | 评委看什么 |
|------|------|-----------|
| **个人成长** | 30 | 家国情怀、调研深度、知识运用能力、学校培养成效 |
| **项目创新** | 30 | 问题导向（解决真实需求）、创新成果（产品/工艺/服务/模式） |
| **产业价值** | 25 | 产业认知（市场规模/趋势）、市场定位、落地前景、社会影响 |
| **团队协作** | 15 | 团队精神、结构合理性、对项目的投入、外部资源 |

### 每个维度的翻译（说人话）

**个人成长（30分）**：
- 你做的项目有没有"立德树人"（不是纯炫技，要有价值观）
- 有没有真的去调研、去实验，不是闭门造车
- 体现你把课堂知识用到了实际问题上
- 体现学校/学院对你的支持

**项目创新（30分）**：
- 是不是从真实问题出发（不是凭空想的）
- 有没有具体的创新成果（样机、专利、论文、软件都算）
- 创新可以从产品、工艺、服务、模式等多个角度体现

**产业价值（25分）**：
- 你了解你做的这个东西的市场吗？（产业规模、竞品、趋势）
- 有商业模式吗？（哪怕粗糙也要有）
- 能落地吗？有没有盈利能力或潜力？

**团队协作（15分）**：
- 团队分工合理吗？
- 你是不是真做了这个项目（不是挂名）

## 六、项目 PPT 结构建议（≤20页）

基于评审规则反推，评委 5 分钟看你的 PPT，他们按这四个维度打分：

```
1. 封面（1页）— 项目名 + 团队 + Logo
2. 痛点/问题（2-3页）— 你要解决什么问题？数据支撑
3. 解决方案（3-4页）— 你的产品/方案是什么？核心技术
4. 创新点（2-3页）— 跟你竞品比，你牛在哪？
5. 市场分析（2页）— 市场多大？目标用户是谁？
6. 商业模式（1-2页）— 怎么赚钱/怎么持续？
7. 团队介绍（1-2页）— 谁在做？各自擅长什么？
8. 项目进展（1-2页）— 做到哪了？样机？数据？
9. 未来规划（1页）— 下一步做什么
10. 封底（1页）— 致谢 + 联系方式
```

---

## 七、项目计划书结构

```
一、项目概述（1页）
   - 一句话说清楚做什么
   - 解决了什么问题

二、项目背景与痛点分析（2-3页）
   - 行业现状、用户痛点
   - 现有方案的不足

三、产品/方案介绍（3-4页）
   - 产品功能、技术架构
   - 核心创新点

四、市场分析（2-3页）
   - 市场规模、目标用户
   - 竞品分析

五、商业模式（1-2页）
   - 盈利模式
   - 推广策略

六、团队介绍（1-2页）
   - 成员分工与优势
   - 指导教师

七、项目进展与规划（1-2页）
   - 已完成的工作
   - 下一步计划

八、财务预测（可选）
```

## 八、全国大学生创业服务网 注册/报名流程

简化版步骤：

1. 打开 cy.ncss.cn → 注册（学信网账号，已有直接登录）
2. 登录后选"创业者" → 完善个人信息（头像、学历、学校、入学/毕业时间、专业）
3. 学籍验证
4. 创建项目 → 填项目名、概述、上传计划书
5. 邀请团队成员（3-15人）→ 成员需在微信公众号确认
6. 点击"报名参赛"

> 💡 不参加校赛的话，计划书直接用大一年度项目立项报告即可，不需要重新写。

## 九、对你的建议（大一视角）

**现实情况**：
- 你是大一，大一年度项目刚起步，创新深度和成果积累肯定不如大三/研究生

**时间还够吗**：
- 校赛报名 5月20日截止 → 还有 **13 天**
- 做一个 PPT + 一份计划书，时间管够
- 关键是先决定"参不参加校赛"
