# 大创校赛 · 项目上下文 — 智能宠物项圈

## 项目概述
- **项目名**: 面向科学养宠的智能项圈系统（智能宠物项圈）
- **一句话**: 解决宠物追踪"测不准、追不到、续航短"三大痛点的全栈智能硬件
- **赛道**: 高教主赛道 · 创意组
- **团队**: 第7组+02（大一年度项目）
- **负责人**: Jack（大一，自主智能系统）

## 技术栈
- **MCU**: STM32
- **传感器**: 心率 PPG、体温、MPU6050 姿态、GPS
- **通信**: 4G Cat.1（EC800K 模块）、A-GPS + LBS 冗余定位
- **云端**: EMQX 消息服务器、WebSocket 全息态势感知大屏
- **算法**: 自适应卡尔曼滤波（运动伪影去除，波动率降低75%）、边缘计算 + 状态机动态功耗管理
- **结构**: 仿生非对称内弧 3D 打印外壳、有源陶瓷天线、射频隔离
- **架构**: 多模态跨频率异步解耦（感知100ms → 计算200ms → 传输1s）
- **下一步**: 60GHz 毫米波雷达（无接触呼吸监测）、微信小程序报警

## 三大核心创新点
1. **测不准** → 仿生贴合结构 + 自适应卡尔曼滤波（波动率↓75%）
2. **追不到** → A-GPS辅助定位 + LBS冗余（TTFF从60s→10s）
3. **续航短** → 边缘计算 + 异常才上报 + ECO/ACT双模式切换
